## Notas técnicas

- **La herramienta Agent con `isolation: worktree` no anda** (el cwd no es repo).
  - Crear los worktrees a mano: `git -C %TEMP%/claude/home-wt worktree add %TEMP%/claude/wt-X -b guia-X origin/main` + `mklink /J` de `frontend/node_modules` desde PowerShell (desde Git Bash falla).

- **Las carpetas de `bot-repo/.git/worktrees/*` dan "Permission denied" al borrarlas** (sandbox). Son restos inofensivos; `git worktree prune` no las puede limpiar.
- **Conflictos de rebase:** cuando varios agentes agregan guías al final de `lib/guias.ts`, chocan siempre. Hay que quedarse con todas y cerrar cada una con `  },`.
