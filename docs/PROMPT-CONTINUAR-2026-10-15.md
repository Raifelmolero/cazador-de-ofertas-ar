## Cómo cargar un lote de ofertas (método que anda)
1. Chrome (extensión Claude in Chrome): `tabs_context_mcp(createIfEmpty)` → `navigate` a `https://www.mercadolibre.com.ar/ofertas?container_id=MLA779357-1&page=1` (o otro container/`/ofertas?page=N`; paginar repite productos, los containers rinden más).
2. JS sobre `.poly-card`: link `a[href*="/p/MLA"],a[href*="/up/MLA"]` (sin `#`/`?`), precios `.andes-money-amount__fraction` ([0]=tachado, [1]=actual), título `.poly-component__title`, imagen `img.src` mlstatic (descartar CBT). Filtrar descuento ≥30 % y precio ≥ $40.000. Guardar en `sessionStorage`; la salida del JS se corta ~1000 caracteres → leer de a 3 ítems.
3. Excluir ids ya cargados: `git fetch origin main` + `git show origin/main:bot/state/ofertas_manuales.json` (el checkout local de `bot-repo` puede estar viejo).
4. Armar `url | título | PRECIO_ACTUAL | PRECIO_ANTERIOR | imagen` separados por ` ;; ` (ojo: actual ANTES que anterior) y correr `gh workflow run oferta_manual.yml -f lote="$(cat lote.txt)"`; verificar con `gh run list --workflow=oferta_manual.yml -L 1` y el conteo en `origin/main`. Cerrar la pestaña al terminar.
